# UI/UX Designer Portfolio

A professional static portfolio website for a UI/UX designer.

## Files

- `index.html` — main landing page
- `assets/css/style.css` — styling for the site
- `assets/js/main.js` — smooth scrolling behavior

## Preview locally

1. Open `index.html` in a browser.
2. Or use a local web server for best results.

## Deploy to get a URL

### Option 1: GitHub Pages

1. Initialize git and commit the project.
2. Push to a GitHub repository.
3. In repository settings, enable GitHub Pages from the `main` branch.
4. Your site will be available at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Netlify

1. Create a free Netlify account.
2. Connect your GitHub repository.
3. Deploy the site from the repository root.
4. Netlify will generate a shareable URL immediately.
